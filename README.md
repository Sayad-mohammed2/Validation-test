# User Registration and Login System with Image Upload

This is a simple web-based registration and login system built using **PHP**, **MySQL**, and **Bootstrap 5**. It includes functionality for:

- User registration with form validation
- Password confirmation
- Image file upload with restrictions on file type and size
- Login authentication with session management

## Features

- Responsive frontend built using Bootstrap 5
- Secure database connection using PDO
- Image upload with validation (`.jpg`, `.jpeg`, `.png`, size < 100KB)
- Stores image filenames in the MySQL database
- Displays uploaded image upon successful login
- Basic session handling

## Technologies Used

- PHP (vanilla)
- MySQL (with PDO)
- Bootstrap 5
- HTML5
